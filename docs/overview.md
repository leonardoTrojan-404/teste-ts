# restaurant-os — Overview

restaurant-os is a SaaS platform that gives small and mid-sized restaurants a
single place to run daily operations.

## Problem

Most restaurants juggle three or four disconnected tools: a POS for orders, a
spreadsheet for the menu, a messaging group for the kitchen, and nothing at all
for customer data. Numbers never reconcile and nobody trusts the reports.

## Scope

| Area                | What it covers                                  |
| ------------------- | ----------------------------------------------- |
| Orders              | Intake, status lifecycle, totals, history        |
| Menu                | Categories, items, pricing, availability         |
| Dashboard           | Live operation metrics and revenue reporting     |
| Customer insights   | Segments, retention, churn signals               |
| Notifications       | Operational alerts for staff                     |

## Non-goals (for now)

- Payment processing (we integrate, we do not become a PSP)
- Inventory and supplier management
- Payroll
